# Examples: MOEPA in Practice

High-level scenario walkthroughs showing how the MOEPA layers and Data Substrate work together for real government AI use cases.

| Scenario | File | Layers |
|---|---|---|
| Third-party income verification | [income-verification.md](income-verification.md) | All 5 + Substrate |

These examples are non-code, scenario-level walkthroughs intended to make the Philosophical AI Architecture concrete for leaders and architects. Each scenario walks through the five MOEPA disciplines as **business outcomes** — trusted data, shared meaning, verifiable truth, governed action, and enforced values.

Architects implementing these patterns should also follow [architectural evolution guidelines](../docs/MOEPA-Architectural-Governance-and-Evolution-Guidelines.md).
